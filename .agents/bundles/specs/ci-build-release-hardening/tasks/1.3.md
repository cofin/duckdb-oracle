# Task 1.3: Fix GITHUB_ENV library path expansion, macOS OCI version/DMG cleanup, and portable sed/sort in shell scripts

## Objective

Remediate findings `M-25` and `M-26` (scripts part) across `scripts/setup_oci_linux.sh`, `scripts/setup_oci_macos.sh`, `scripts/setup_oci_windows.ps1`, `scripts/test_integration.sh`, and `scripts/bump_duckdb_version.sh`:
1. In `scripts/setup_oci_linux.sh`:
   - Remove the unversioned `LATEST_BASE_URL` fallback so downloads are deterministic.
   - Use `export LD_LIBRARY_PATH="${OCI_HOME}${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"` (safe under `set -u`) and write `echo "LD_LIBRARY_PATH=${LD_LIBRARY_PATH}" >> "$GITHUB_ENV"` instead of literal `\$LD_LIBRARY_PATH`.
2. In `scripts/setup_oci_macos.sh`:
   - Bump `OCI_VERSION` to `23.26.2.0.0` (`23_26`), use `set -euo pipefail`, download into `$INSTALL_DIR` with `curl -fL --retry 3`, register an `EXIT` trap to detach any mounted DMGs, and write expanded `DYLD_LIBRARY_PATH=${DYLD_LIBRARY_PATH}` to `"$GITHUB_ENV"`.
3. In `scripts/setup_oci_windows.ps1`:
   - Download `basic.zip` and `sdk.zip` into `$INSTALL_DIR` instead of the repository working directory.
4. In `scripts/test_integration.sh`:
   - Sort integration `.test` files deterministically (`find ... -print0 | sort -z`), avoid running the test loop in a subshell pipeline, replace fragile `sed` `/` substitution with Python/awk environment variable substitution (safe when passwords contain `/`, `&`, or `\`), and fall back to `python3` socket binding or `/dev/tcp` when `nc` is not installed.
5. In `scripts/bump_duckdb_version.sh`:
   - Replace non-portable `sed -i -E` with portable replacement (`python3` or temp-file `sed -E`), and match space-padded `docs/COMPATIBILITY.md` table rows with `grep -Eq "^\|[[:space:]]*${TAG}[[:space:]]*\|"`.

## Steps

### Step 1: Update `scripts/setup_oci_linux.sh`, `scripts/setup_oci_macos.sh`, and `scripts/setup_oci_windows.ps1`

- In `scripts/setup_oci_linux.sh`:
  - Remove `LATEST_BASE_URL` fallback.
  - Set `export LD_LIBRARY_PATH="${OCI_HOME}${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"` and write `echo "LD_LIBRARY_PATH=${LD_LIBRARY_PATH}" >> "$GITHUB_ENV"`.
- In `scripts/setup_oci_macos.sh`:
  - Set `set -euo pipefail` and `OCI_VERSION="${OCI_VERSION:-23.26.2.0.0}"`.
  - Add `MOUNT_POINTS=()` and `cleanup_mounts() { for mp in "${MOUNT_POINTS[@]:-}"; do [ -n "$mp" ] && hdiutil detach "$mp" -quiet || true; done; }; trap cleanup_mounts EXIT`.
  - Use `curl -fL --retry 3` downloading into `$INSTALL_DIR`.
  - Set `export DYLD_LIBRARY_PATH="${OCI_HOME}${DYLD_LIBRARY_PATH:+:$DYLD_LIBRARY_PATH}"` and write `echo "DYLD_LIBRARY_PATH=${DYLD_LIBRARY_PATH}" >> "$GITHUB_ENV"`.
- In `scripts/setup_oci_windows.ps1`:
  - Download `$INSTALL_DIR\basic.zip` and `$INSTALL_DIR\sdk.zip`.

### Step 2: Update `scripts/test_integration.sh` and `scripts/bump_duckdb_version.sh`

- In `scripts/test_integration.sh`:
  - Use `while IFS= read -r -d '' test_file; do ... done < <(find "$TEST_DIR" -name "*.test" -print0 | sort -z)`.
  - Substitute `${ORACLE_HOST}`, `${ORACLE_PORT}`, `${ORACLE_SERVICE}`, `${ORACLE_USER}`, and `${ORACLE_PASSWORD}` using `python3 -c` reading from environment variables so special characters in passwords never break `sed`.
  - In `get_free_port`, check `command -v nc` and fall back to `python3 -c 'import socket; s=socket.socket(); s.bind(("", 0)); print(s.getsockname()[1]); s.close()'`.
- In `scripts/bump_duckdb_version.sh`:
  - Replace `sed -i` / `sed -i -E` calls with portable temp-file or `python3` in-place updates, and use `grep -Eq "^\|[[:space:]]*${TAG}[[:space:]]*\|" docs/COMPATIBILITY.md`.
