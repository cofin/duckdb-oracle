# Task 1.4: Align description.yml license with LICENSE, configure extension_config.cmake TEST_DIR, and harden CMakeLists.txt & Makefile

## Objective

Remediate findings `H-24` (license part), `M-26` (CMake/Makefile part), and `L-10` in `extension_config.cmake`, `CMakeLists.txt`, `Makefile`, `description.yml`, and `LICENSE`:
1. Update `description.yml:7` from `license: Apache-2.0` to `license: MIT` so it matches `LICENSE` (`MIT License`).
2. In `extension_config.cmake`, pass `TEST_DIR ${CMAKE_CURRENT_LIST_DIR}/test/unit_tests` to `duckdb_extension_load(oracle ...)`.
3. In `CMakeLists.txt`, update `cmake_minimum_required(VERSION 3.15)` and replace the single hardcoded `/usr/share/oracle/instantclient_23_26` fallback with a `file(GLOB ...)` over `/usr/share/oracle/instantclient_*` and `/opt/oracle/instantclient_*` when `ORACLE_HOME` is unset.
4. In `Makefile`:
   - In `ensure_libaio`, use `SUDO=""; if [ "$$(id -u)" -ne 0 ] && command -v sudo >/dev/null 2>&1; then SUDO="sudo"; fi` before `apt-get`.
   - Add `ensure-libaio` as a prerequisite of `test_debug_internal` and `test_reldebug_internal` in addition to `test_release_internal`.
