# Task 1.2: Preserve per-ATTACH settings, add call timeout & statement cache settings, and harden connection string resolution

## Objective

Remediate findings `H-04` (resolver part), `H-05`, `M-02` (settings part), `M-03`, and `M-07` (resolver part) in `src/include/oracle_settings.hpp`, `src/oracle_settings.cpp`, `src/include/oracle_connection_resolver.hpp`, and `src/oracle_connection_resolver.cpp`:
1. Preserve per-`ATTACH` options (`ENABLE_PUSHDOWN`, `PREFETCH_ROWS`, `ARRAY_SIZE`, `LAZY_SCHEMA_LOADING`, etc.) when `GetOracleSettings(context, state)` resolves settings for an attached catalog.
2. Add `call_timeout_ms = 30000` (`oracle_call_timeout_ms`, range `0..3600000`) and `stmt_cache_size = 20` (`oracle_stmt_cache_size`, range `0..1024`) to `OracleSettings`.
3. Guard `UBIGINT` option retrieval against `> NumericLimits<int64_t>::Maximum()` overflow.
4. Update `HasDirectConnectionStringShape` to use `rfind('@')` and accept `/@connect_identifier`.
5. Populate `resolved.catalog_state = state_hint` in `ResolveOracleConnection` when `state_hint` is non-null.

## Context

- **Root Cause of `H-05`**: `DBConfig::AddExtensionOption` (`duckdb/src/main/config.cpp:501-504`) immediately calls `SetOption(name, Value(default_value))` into `db_config.user_settings`. Consequently, `context.TryGetCurrentSetting(key, val)` in `GetOracleSettings` (`src/oracle_connection_resolver.cpp:26-70`) *always* returns a truthy `SettingScope::GLOBAL` result and overwrites `state->settings` with global defaults, wiping out every per-`ATTACH` option applied by `OracleCatalogState::ApplyOptions`.
- **Relevant Source Locations**:
  - `src/include/oracle_settings.hpp:17-39`
  - `src/oracle_settings.cpp:8-82`
  - `src/oracle_connection_resolver.cpp:11-91`

## Steps

### Step 1: Add `call_timeout_ms`, `stmt_cache_size`, and explicit override tracking to `OracleSettings`

In `src/include/oracle_settings.hpp`:
- Add `idx_t call_timeout_ms = 30000;` (`0` disables timeout, max `3600000`) and `idx_t stmt_cache_size = 20;` (`0` disables OCI statement cache, max `1024`).
- Add `unordered_set<string> attach_overridden_keys;` (or boolean flags per field) populated by `ApplyAttachOptions(const case_insensitive_map_t<Value> &options, OracleSettings &settings)` when an `ATTACH` option is explicitly provided.

In `src/oracle_settings.cpp`:
- Register `"oracle_call_timeout_ms"` (`LogicalType::UBIGINT`, default `Value::UBIGINT(30000)`) and `"oracle_stmt_cache_size"` (`LogicalType::UBIGINT`, default `Value::UBIGINT(20)`).
- Support `"call_timeout_ms"` and `"stmt_cache_size"` in `ApplyAttachOptions`, recording each matched option's corresponding setting key (e.g. `"oracle_enable_pushdown"`, `"oracle_prefetch_rows"`, etc.) in `settings.attach_overridden_keys`.
- Validate in `ValidatePositiveRange` that `val >= 0`.

### Step 2: Preserve per-`ATTACH` overrides in `GetOracleSettings` and guard `UBIGINT` conversions

In `src/oracle_connection_resolver.cpp:20-71`:
- When `state` is non-null, start with `OracleSettings settings = state->settings;`.
- Helper lambda `ShouldApplySetting(const string &name, SettingScope scope)`: return `true` if `!state` or `scope == SettingScope::LOCAL` or `state->settings.attach_overridden_keys.find(name) == state->settings.attach_overridden_keys.end()`.
- Helper lambda `ExtractBoundedUbigint(const Value &val, const string &name, int64_t min_val, int64_t max_val)`:
  ```cpp
  auto raw = val.GetValue<uint64_t>();
  if (raw > static_cast<uint64_t>(NumericLimits<int64_t>::Maximum())) {
      throw InvalidInputException("Invalid value for %s: out of range [%lld, %lld]", name, min_val, max_val);
  }
  auto signed_val = static_cast<int64_t>(raw);
  ValidatePositiveRange(name, signed_val, min_val, max_val);
  return static_cast<idx_t>(signed_val);
  ```
- Apply `oracle_call_timeout_ms` (`0..3600000`) and `oracle_stmt_cache_size` (`0..1024`) using the same helper.

### Step 3: Fix `HasDirectConnectionStringShape` and `ResolveOracleConnection` in `src/oracle_connection_resolver.cpp`

In `src/oracle_connection_resolver.cpp:11-16`:
```cpp
static bool HasDirectConnectionStringShape(const string &connection_string) {
	auto slash_pos = connection_string.find('/');
	auto at_pos = connection_string.rfind('@');
	if (slash_pos == string::npos || at_pos == string::npos || slash_pos >= at_pos) {
		return false;
	}
	if (at_pos + 1 >= connection_string.size()) {
		return false;
	}
	if (slash_pos == 0) {
		return at_pos == 1;
	}
	return true;
}
```
And in `ResolveOracleConnection` (`src/oracle_connection_resolver.cpp:73-91`), when `state_hint` is non-null, assign `resolved.catalog_state = state_hint;` before returning.
