# Task 1.4: Fix OCIEnv lifetime, ScopedTnsAdmin concurrency, pooled session health checks, and session initialization

## Objective

Remediate findings `H-01`, `H-02`, `H-03`, `H-04` (manager part), `M-02` (manager part), `M-04`, `M-08` (password scrubbing), and `L-03` (manager part) in `src/include/oracle_connection_manager.hpp` and `src/oracle_connection_manager.cpp`:
1. Add `std::shared_ptr<OCIEnv> env_owner;` to `OracleContext` (while keeping raw `OCIEnv *envhp`, `OCIError *errhp`, `OCISvcCtx *svchp`, `OCIServer *srvhp`, `OCISession *authp` for caller compatibility) and change `OracleConnectionManager::env` to `std::shared_ptr<OCIEnv>` initialized with `OCI_THREADED | OCI_OBJECT`.
2. Make `ScopedTnsAdmin` a no-op when `wallet_path.empty()`, skip `SetOracleEnvVar` if `TNS_ADMIN` already matches `wallet_path`, preserve `TNS_ADMIN=""` via `bool had_previous`, and release `ScopedTnsAdmin` immediately after `OCISessionBegin`.
3. Add `IsOracleContextHealthy(OracleContext &ctx, bool ping_server)` (`OCI_ATTR_SERVER_STATUS == OCI_SERVER_NORMAL` and `OCIPing`); roll back uncommitted work (`OCITransRollback`) and check health in `~OracleConnectionHandle()` before returning to `pool->idle`; validate health in `Acquire()`; and wire `MarkUnusable()`.
4. Parse connection strings with `rfind('@')`, support `/@connect_identifier` with `OCI_CRED_EXT`, and scrub `std::string password` immediately after `OCISessionBegin`.
5. Configure `OCI_ATTR_CALL_TIMEOUT` from `settings.call_timeout_ms` (via `CheckOCIOptionalAttributeORA24315`), configure `OCI_ATTR_STMTCACHESIZE` from `settings.stmt_cache_size`, and add `NLS_NUMERIC_CHARACTERS = '.,'` and `NLS_TIMESTAMP_TZ_FORMAT = 'YYYY-MM-DD HH24:MI:SS.FF TZH:TZM'` to session initialization SQL.
6. Check deadline expiration on `pool->stale` retry in `Acquire()` and call `pool->cv.notify_one()` after unlocking `pool->lock` in `~OracleConnectionHandle()`.

### Step 1: Share `std::shared_ptr<OCIEnv>` and remove dead fields in `src/include/oracle_connection_manager.hpp`

In `src/include/oracle_connection_manager.hpp`:
- Add `std::shared_ptr<OCIEnv> env_owner;` to `OracleContext` (preserving `OCIEnv *envhp = nullptr;`, `OCIError *errhp = nullptr;`, `OCISvcCtx *svchp = nullptr;`, `OCIServer *srvhp = nullptr;`, `OCISession *authp = nullptr;`, and freeing `authp`, `svchp`, `srvhp`, `errhp` before `env_owner.reset()` in `~OracleContext()`).

### Step 2: Fix `ScopedTnsAdmin`, `ParseOracleConnectionString`, and `OCIEnvCreate` in `src/oracle_connection_manager.cpp`

- In `ScopedTnsAdmin` (`src/oracle_connection_manager.cpp:11-41`):
  - Construct `std::unique_lock<std::mutex> lock(WalletEnvLock(), std::defer_lock);`.
  - Only lock `WalletEnvLock()` and inspect `getenv("TNS_ADMIN")` when `!wallet_path.empty()`.
  - Track `bool had_previous = false;` and `bool mutated = false;`. If `current && wallet_path == current`, do not call `SetOracleEnvVar`. Otherwise set `mutated = true` and call `SetOracleEnvVar("TNS_ADMIN", wallet_path.c_str())`.
  - In `~ScopedTnsAdmin()` (and an explicit `Release()` method), if `mutated`: call `SetOracleEnvVar("TNS_ADMIN", previous_value.c_str())` when `had_previous`, else `UnsetOracleEnvVar("TNS_ADMIN")`.
- In `ParseOracleConnectionString` (`src/oracle_connection_manager.cpp:45-56`):
  - Use `auto at_pos = conn_str.rfind('@');`.
  - Allow `slash_pos == 0 && at_pos == 1` (`user = ""`, `password = ""`, `db = conn_str.substr(2)`), throwing `IOException("Invalid Oracle connection string format. Expected user/password@connect_identifier or /@connect_identifier.")` on invalid shapes.
- In `OracleConnectionManager::OracleConnectionManager()` (`src/oracle_connection_manager.cpp:117`):
  - Pass `OCI_THREADED | OCI_OBJECT` to `OCIEnvCreate` and store in `std::shared_ptr<OCIEnv>(raw_env, [](OCIEnv *p) { if (p) OCIHandleFree(p, OCI_HTYPE_ENV); })`.

### Step 3: Add `IsOracleContextHealthy`, rollback on release, deadline check on retry, and post-unlock `notify_one`

- Add `static bool IsOracleContextHealthy(OracleContext &ctx, bool ping_server)`:
  ```cpp
  if (!ctx.srvhp || !ctx.svchp || !ctx.errhp) {
      return false;
  }
  ub4 server_status = OCI_SERVER_NOT_CONNECTED;
  if (OCIAttrGet(ctx.srvhp, OCI_HTYPE_SERVER, &server_status, nullptr, OCI_ATTR_SERVER_STATUS, ctx.errhp) != OCI_SUCCESS ||
      server_status != OCI_SERVER_NORMAL) {
      return false;
  }
  if (ping_server) {
      if (OCIPing(ctx.svchp, ctx.errhp, OCI_DEFAULT) != OCI_SUCCESS) {
          return false;
      }
  }
  return true;
  ```
- In `OracleConnectionHandle::~OracleConnectionHandle()` (`src/oracle_connection_manager.cpp:92-108`):
  - Before acquiring `pool->lock`, if `!unusable && !pool->stale && ctx`: call `OCITransRollback(ctx->svchp, ctx->errhp, OCI_DEFAULT)` and check `IsOracleContextHealthy(*ctx, false)` (setting `unusable = true` if unhealthy).
  - Acquire `std::unique_lock<std::mutex> guard(pool->lock);`, push `ctx` to `pool->idle` or decrement `pool->total`, then call `guard.unlock(); pool->cv.notify_one();`.
- In `OracleConnectionManager::Acquire` (`src/oracle_connection_manager.cpp:168-254`):
  - When popping from `pool->idle`, verify `IsOracleContextHealthy(*ctx, true)` outside `pool->lock`; if unhealthy, decrement `pool->total` and create a fresh connection.
  - On `pool->stale` retry (line 237), check `std::chrono::steady_clock::now() >= deadline` before continuing.

### Step 4: Update `CreateConnection` with SEPS `OCI_CRED_EXT`, password scrubbing, call timeout, statement cache, and NLS settings

In `OracleConnectionManager::CreateConnection` (`src/oracle_connection_manager.cpp:256-334`):
