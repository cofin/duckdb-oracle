# Task 1.3: Support SEPS wallet credentials, TNS aliases without host, and strict secret parameter validation

## Objective

Remediate findings `H-04` (secret part), `M-06`, and `L-03` (secret part) in `src/include/oracle_secret.hpp` and `src/oracle_secret.cpp`:
1. Allow `user` and `password` to be omitted when `wallet_path` is provided (building `/@<connect_target>` for Secure External Password Store / SEPS authentication), while rejecting secrets where only one of `user` or `password` is provided.
2. Track `bool host_provided = false;` in `OracleSecretParameters` so that when `wallet_path` is set and `host` was not explicitly provided, `BuildConnectionStringFromSecret` emits `<creds>@<service>` (TNS alias in `tnsnames.ora`) instead of `@localhost:1521/<service>`.
3. Reject `'/'` in `params.user`, reject empty `params.host` when host-based EZConnect is used, and validate signed port values (`1..65535`) before casting to `idx_t`.
4. Remove unused `OracleSecretParameters::database` and unused `#include` directives (`"oracle_utils.hpp"`, `<cstdlib>`).

## Context

- **Relevant Source Locations**:
  - `src/include/oracle_secret.hpp:10-28` (`OracleSecretParameters`)
  - `src/oracle_secret.cpp:1-148` (`ReadSecretParameters`, `CreateOracleSecretFromConfig`, `ValidateOracleSecret`, `BuildConnectionStringFromSecret`)

## Steps

### Step 1: Update `OracleSecretParameters` in `src/include/oracle_secret.hpp`

In `src/include/oracle_secret.hpp:10-21`:
- Remove `string database;`.
- Add `bool host_provided = false;`.

### Step 2: Update parameter extraction and validation in `src/oracle_secret.cpp`

In `src/oracle_secret.cpp`:
- Remove unused `#include "oracle_utils.hpp"` and `#include <cstdlib>`.
- In `ReadSecretParameters` (`src/oracle_secret.cpp:21-60`) and `CreateOracleSecretFromConfig` (`src/oracle_secret.cpp:62-80`):
  - When `"host"` is present in options/secret map, set `params.host_provided = true;`.
  - When `"database"` is provided and `"service"` is empty, assign directly to `params.service`.
  - Validate `"port"` as `int64_t` in `[1, 65535]` before assigning `params.port = static_cast<idx_t>(raw_port)`.
- In `ValidateOracleSecret` (`src/oracle_secret.cpp:82-122`):
  - If `!params.connection_string.empty()`, validate that if `params.user.empty() != params.password.empty()`, throw `InvalidInputException`.
  - When `params.connection_string.empty()`:
    - Require `!params.service.empty()`.
    - If `params.wallet_path.empty()`: require both `!params.user.empty()` and `!params.password.empty()`.
    - If `!params.wallet_path.empty()`: allow both `params.user.empty() && params.password.empty()` (SEPS wallet) OR both non-empty; if only one of `user` or `password` is set, throw `InvalidInputException("Oracle WALLET_PATH secret requires either both USER and PASSWORD or neither (for external password store)")`.
    - If `params.user.find('/') != string::npos`, throw `InvalidInputException("Oracle secret USER cannot contain '/'")`.
    - If `(params.wallet_path.empty() || params.host_provided) && params.host.empty()`, throw `InvalidInputException("Oracle secret HOST cannot be empty")`.

### Step 3: Build SEPS and TNS alias connection strings in `BuildConnectionStringFromSecret`

In `src/oracle_secret.cpp:124-148`:
```cpp
string BuildConnectionStringFromSecret(const KeyValueSecret &secret) {
	auto params = ReadSecretParameters(secret);
	ValidateOracleSecret(params);
	if (!params.connection_string.empty()) {
		if (!params.user.empty() && !params.password.empty() && params.connection_string.find('/') == string::npos) {
			return params.user + "/" + params.password + "@" + params.connection_string;
		}
		return params.connection_string;
	}
	string creds = (params.user.empty() && params.password.empty()) ? "/" : (params.user + "/" + params.password);
	if (!params.wallet_path.empty() && !params.host_provided) {
		return creds + "@" + params.service;
	}
	return creds + "@" + params.host + ":" + to_string(params.port) + "/" + params.service;
}
```
