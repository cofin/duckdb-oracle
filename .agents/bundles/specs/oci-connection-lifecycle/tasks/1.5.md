# Task 1.5: Deduplicate OracleConnection::Query, remove double execution, detect truncation, and fix empty string binds

## Objective

Remediate findings `H-06`, `M-05`, and `L-03` (connection part) in `src/include/oracle_connection.hpp` and `src/oracle_connection.cpp`:
1. Delegate `OracleConnection::Query(const std::string &query)` directly to `QueryWithStringBinds(query, {})`, eliminating ~80 lines of duplicated OCI boilerplate.
2. Remove the redundant `OCIStmtExecute(..., OCI_DESCRIBE_ONLY)` call before `OCIStmtExecute(..., OCI_DEFAULT)`.
3. Initialize `OraText *col_name = nullptr;`, size per-column fetch buffers using `OCI_ATTR_DATA_SIZE` (up to `65535` bytes for `CLOB`/`LONG` metadata columns like `ALL_VIEWS.TEXT` or `HIGH_VALUE`), and check `indicators[i] == -2 || indicators[i] > 0` to throw `IOException` instead of silently truncating at 4095 bytes.
4. Bind empty string parameters with `bind_indicators[i] = -1` (`OCI_IND_NULL`) and buffer capacity `>= 1`.
5. Remove dead `OracleConnection::Commit()`, `OracleConnection::Rollback()`, unused `idx_t rows`, and unused `#include` headers.

## Context

- **Relevant Source Locations**:
  - `src/include/oracle_connection.hpp:20-40`

## Steps

### Step 1: Remove dead `Commit()` and `Rollback()` declarations in `src/include/oracle_connection.hpp`

In `src/include/oracle_connection.hpp:30-35`, remove `void Commit();` and `void Rollback();`.

### Step 2: Refactor `Query` and `QueryWithStringBinds` in `src/oracle_connection.cpp`

In `src/oracle_connection.cpp`:
- Remove unused `#include <cstring>`, `#include <iostream>`, and `#include <sstream>`.
- Implement `Query(const std::string &query)` as:
  ```cpp
  OracleResult OracleConnection::Query(const std::string &query) {
      return QueryWithStringBinds(query, {});
  }
  ```
- In `QueryWithStringBinds(const std::string &query, const std::vector<std::string> &binds)`:
  - For each bind parameter `i`:
    ```cpp
    bind_indicators[i] = binds[i].empty() ? static_cast<sb2>(-1) : static_cast<sb2>(0);
    bind_storage[i].assign(binds[i].begin(), binds[i].end());
    bind_storage[i].push_back('\0');
    ```
  - Execute `OCIStmtExecute(ctx->svchp, stmthp.get(), ctx->errhp, 0, 0, nullptr, nullptr, OCI_DEFAULT)` once (removing the preceding `OCI_DESCRIBE_ONLY` call).
  - For each column `1..col_count`:
    - Initialize `OraText *col_name = nullptr; ub4 col_name_len = 0;` and check `OCIAttrGet` with `CheckOCIError`.
    - Query `ub2 data_type = 0;` and `ub2 data_size = 0;` from `mypard`. Size the buffer as `ub4 buf_size = (data_type == SQLT_CLOB || data_type == SQLT_BLOB || data_type == SQLT_LNG) ? 65535 : MaxValue<ub4>(static_cast<ub4>(data_size) * 4 + 1, 4096); buf_size = MinValue<ub4>(buf_size, 65535);`.
  - In the `OCIStmtFetch2` loop:
    - Accept both `OCI_SUCCESS` and `OCI_SUCCESS_WITH_INFO`.
    - For each column `i`, if `indicators[i] == -1`, append `""`; if `indicators[i] == -2 || indicators[i] > 0`, throw `IOException("Oracle metadata query column '%s' exceeded fetch buffer size (%u bytes)", res.columns[i], static_cast<unsigned>(buffers[i].size()))`; otherwise append `std::string(buffers[i].data(), return_lens[i])`.
    - When `status == OCI_SUCCESS_WITH_INFO`, if `OCIErrorCodeMatches(ctx->errhp, 1406)`, throw `IOException`.
- Delete `OracleConnection::Commit()` and `OracleConnection::Rollback()`.
