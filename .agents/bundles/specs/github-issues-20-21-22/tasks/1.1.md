# Task 1.1: Refactor `OracleCatalog` and `OracleSchemaEntry` to Native DuckDB Catalog Hierarchy with Cache Generation Sync and Scan Resilience

## Objective
Resolve all root causes of GitHub Issue #21 (`duckdb_databases()`, `duckdb_schemas()`, `duckdb_tables()`, `duckdb_columns()`, `information_schema.*`, and `SHOW TABLES` failures and empty system views):
1. Remove `DuckCatalog` and `DuckSchemaEntry` (`CatalogSet`) inheritance so `OracleCatalog` inherits directly from `Catalog` and `OracleSchemaEntry` inherits directly from `SchemaCatalogEntry`, eliminating the `D_ASSERT(catalog_p.IsDuckCatalog())` assertion violation in debug builds (`duckdb/src/catalog/catalog_set.cpp:85`).
2. Set `info.internal = false` on all created `OracleSchemaEntry` objects so DuckDB system views (`duckdb_schemas`, `duckdb_tables`, `duckdb_columns`, `information_schema.*`) include attached Oracle schemas, tables, and columns.
3. Add an atomic cache generation counter (`cache_generation`) to `OracleCatalogState` incremented on `ClearCaches()`, and synchronize `OracleCatalog` and `OracleSchemaEntry` caches against it while retaining evicted entries in `retired_schemas` / `retired_tables` to guarantee pointer stability for in-flight queries.
4. Filter `SYNONYM` entries in `OracleCatalogState::ListObjects` so only local (`db_link IS NULL`) synonyms pointing to `TABLE`, `VIEW`, or `MATERIALIZED VIEW` objects in `all_objects` are enumerated, and make `OracleSchemaEntry::Scan` gracefully skip tables that fail `OracleTableEntry::Create` (e.g., tables with unsupported column types such as `ROWID`, `LONG`, `BFILE`, or disabled `SDO_GEOMETRY`) while keeping `OracleSchemaEntry::LookupEntry` strict (`NotImplementedException` when querying an unsupported table directly).
5. Populate `NotNullConstraint` on `CreateTableInfo::constraints` in `OracleTableEntry::Create` / `LoadColumns` when `all_tab_columns.nullable == "N"`.

### 2. `src/storage/oracle_catalog.cpp`
- **In `OracleCatalogState::ClearCaches()` (`src/storage/oracle_catalog.cpp:113-120`)**:
  Increment `cache_generation` under `lock`:
  ```cpp
  void OracleCatalogState::ClearCaches() {
  	lock_guard<std::mutex> guard(lock);
  	schema_cache.clear();
  	object_cache.clear();
  	current_schema.clear();
  	version_detected = false;
  	version_info = OracleVersionInfo();
  	cache_generation.fetch_add(1, std::memory_order_acq_rel);
  }
  ```
- **In `OracleCatalogState::ListObjects(const string &schema, const string &object_types)` (`src/storage/oracle_catalog.cpp:317-323`)**:
  Filter `SYNONYM` rows in `all_objects` so non-table synonyms (pointing to sequences, packages, procedures, functions, types, remote `db_link`s, or missing targets) are excluded during object enumeration:
  ```cpp
  	auto metadata_result_limit = OracleEffectiveMetadataResultLimit(settings);
  	string query = StringUtil::Format(
  	    "SELECT * FROM ("
  	    "SELECT DISTINCT o.object_name FROM all_objects o "
  	    "WHERE (o.owner = :1 OR o.owner = UPPER(:2)) AND o.object_type IN (%s) "
  	    "AND (o.object_type != 'SYNONYM' OR EXISTS ("
  	    "SELECT 1 FROM all_synonyms s "
  	    "JOIN all_objects target_obj ON target_obj.owner = s.table_owner AND target_obj.object_name = s.table_name "
  	    "WHERE s.owner = o.owner AND s.synonym_name = o.object_name "
  	    "AND s.db_link IS NULL AND target_obj.object_type IN ('TABLE', 'VIEW', 'MATERIALIZED VIEW')"
  	    ")) "
  	    "ORDER BY o.object_name"
  	    ") WHERE ROWNUM <= %llu",
  	    types_sql.c_str(), static_cast<uint64_t>(metadata_result_limit));
  ```
- **In `OracleCatalogState::GetRealSchemaName(const string &name)` (`src/storage/oracle_catalog.cpp:510-521`)**:
  Fall back to `current_schema` if `all_users` returns no match and `name` matches `current_schema` case-insensitively:
  ```cpp
  string OracleCatalogState::GetRealSchemaName(const string &name) {
  	auto query = "SELECT username FROM all_users "
  	             "WHERE (username = :1 OR username = UPPER(:2)) "
  	             "ORDER BY CASE WHEN username = :3 THEN 0 ELSE 1 END, username "
  	             "FETCH FIRST 1 ROWS ONLY";

  	auto result = ExecuteMetadataQueryWithStringBinds(query, {name, name, name});
  	if (!result.rows.empty() && !result.rows[0].empty()) {
  		return result.rows[0][0];
  	}
  	auto current = GetCurrentSchema();
  	if (!current.empty() && StringUtil::CIEquals(name, current)) {
  		return current;
  	}
  	return "";
  }
  ```

### 4. `src/storage/oracle_schema_entry.cpp`
- Refactor `OracleSchemaEntry` to inherit directly from `SchemaCatalogEntry` (removing `DuckSchemaEntry`, `OracleTableGenerator`, `OracleSchemaGenerator`, `duck_schema_entry.hpp`, `duck_catalog.hpp`, and `default_generator.hpp`).
- Implement `OracleSchemaEntry::LookupEntry`, `OracleSchemaEntry::GetSimilarEntry`, and both `OracleSchemaEntry::Scan` overloads:
  - `SyncCacheGenerationLocked()` checks `state->GetCacheGeneration()`; when the generation changes, moves all entries from `tables` to `retired_tables`, clears `tables` and `unresolvable_entries`, sets `tables_enumerated = false`, and updates `cached_generation`.
  - `LoadTableEntryLocked(const string &entry_name)` checks `tables` first; if not present, calls `state->GetObjectName(oracle_schema, entry_name, "'TABLE','VIEW','MATERIALIZED VIEW'", real_owner, real_name)` and `OracleTableEntry::Create(catalog, *this, real_owner, real_name, state, real_name)` (or falls back to `state->ResolveSynonym(oracle_schema, entry_name, found)` and `OracleTableEntry::Create(catalog, *this, resolved.first, resolved.second, state, entry_name)`), caches the created `OracleTableEntry` in `tables[entry->name]`, and returns it.
  - `LookupEntry(CatalogTransaction transaction, const EntryLookupInfo &lookup_info)` returns `nullptr` for `lookup_info.GetCatalogType() != CatalogType::TABLE_ENTRY`; otherwise acquires `table_lock`, calls `SyncCacheGenerationLocked()`, and returns `LoadTableEntryLocked(lookup_info.GetEntryName())` (propagating `NotImplementedException` when an unsupported table is explicitly queried).
  - `GetSimilarEntry(CatalogTransaction transaction, const EntryLookupInfo &lookup_info)` returns `SimilarCatalogEntry()` immediately if `lookup_info.GetCatalogType() != CatalogType::TABLE_ENTRY`; otherwise scores `lookup_info.GetEntryName()` using `StringUtil::SimilarityRating` against the object names returned by `state->ListObjects(oracle_schema, state->settings.metadata_object_types)` (wrapped in `try { ... } catch (...) {}`) and any keys already in `tables` without calling `LoadTableEntryLocked`, preventing missing-table lookups from triggering $N$ `all_tab_columns` queries via `SchemaCatalogEntry::GetSimilarEntry`'s default `Scan` implementation.
  - `Scan(CatalogType type, const std::function<void(CatalogEntry &)> &callback)` returns immediately for `type != CatalogType::TABLE_ENTRY`; otherwise under `table_lock` calls `SyncCacheGenerationLocked()`, enumerates `state->ListObjects(oracle_schema, state->settings.metadata_object_types)` once per cache generation, attempts `LoadTableEntryLocked(obj_name)` inside a `try { ... } catch (const Exception &) { unresolvable_entries.insert(obj_name); }` block (also recording `unresolvable_entries.insert(obj_name)` if `LoadTableEntryLocked` returns `nullptr`), collects sorted `vector<reference<CatalogEntry>>`, releases `table_lock`, and invokes `callback(entry.get())`.
  - `Scan(ClientContext &context, CatalogType type, const std::function<void(CatalogEntry &)> &callback)` delegates to `Scan(type, callback)`.
- Implement `OracleCatalog` methods (`LookupSchema`, `ScanSchemas`, `GetDefaultSchema`, `SyncCacheGenerationLocked`, `GetOrCreateSchemaLocked`):
  - All `OracleSchemaEntry` instances are created with `info.internal = false`.
  - When `(StringUtil::CIEquals(entry_name, DEFAULT_SCHEMA) || StringUtil::CIEquals(entry_name, "main")) && state->settings.use_current_schema`, map `"main"` to `oracle_schema = current_schema`.
  - When `verify_exists == false` (called from `ScanSchemas` for names returned by `state->ListSchemas()`), construct `OracleSchemaEntry` directly without calling `state->GetRealSchemaName(entry_name)`.
  - When `verify_exists == true` (called from `LookupSchema`), call `state->GetRealSchemaName(entry_name)`; if empty, return `nullptr` (and in `LookupSchema`, if `if_not_found == OnEntryNotFound::THROW_EXCEPTION`, throw `CatalogException::MissingEntry(schema_lookup, "")`).
  - In `OracleCatalog::GetDefaultSchema()`, return `DEFAULT_SCHEMA` when `!state || state->settings.use_current_schema`; when `!state->settings.use_current_schema`, return `state->GetCurrentSchema()` if non-empty, otherwise `DEFAULT_SCHEMA`.
