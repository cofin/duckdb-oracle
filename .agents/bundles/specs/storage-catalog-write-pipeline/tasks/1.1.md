# Task 1.1: Isolate per-ATTACH OracleCatalogState, synchronize OracleTransactionManager, and validate ATTACH options

## Objective

Remediate findings `H-18`, `H-20`, and `L-08` (storage extension part) in `src/include/oracle_storage_extension.hpp`, `src/storage/oracle_storage_extension.cpp`, `src/include/oracle_transaction_manager.hpp`, and `src/storage/oracle_transaction_manager.cpp`:
1. Remove the singleton `OracleStorageInfo` state cache so every `OracleAttach` allocates a fresh `make_shared_ptr<OracleCatalogState>(connection_string, wallet_path)`, applies its own `ATTACH` options, and calls `OracleCatalogState::Register(state, name)`.
2. Retrieve `state` in `OracleCreateTransactionManager` via `OracleCatalogState::LookupByAlias(db.GetName())` instead of `storage_info`.
3. Add `std::mutex transaction_lock;` to `OracleTransactionManager` to synchronize `active` across `StartTransaction` and `EraseTransaction`.
4. Match `secret` and `wallet_path` case-insensitively in `OracleAttach`, throw `BinderException` when both a non-empty `info.path` and `SECRET` option are supplied, and remove dead `options.access_mode` / `info.path` writes.

- **Relevant Source Locations**:

  - `src/storage/oracle_storage_extension.cpp:15-122`
  - `src/include/oracle_transaction_manager.hpp:15-25`
  - `src/storage/oracle_transaction_manager.cpp:11-47`

## Steps

### Step 1: Remove `OracleStorageInfo` and isolate per-`ATTACH` state in `src/storage/oracle_storage_extension.cpp`

- Remove `struct OracleStorageInfo` from `src/include/oracle_storage_extension.hpp`.
- In `OracleAttach` (`src/storage/oracle_storage_extension.cpp:15-99`):
  - Scan `info.options` case-insensitively (`StringUtil::Lower(entry.first)`) for `"secret"` and `"wallet_path"`.
  - If `!info.path.empty() && has_secret_option`, throw `BinderException("Cannot specify both a connection string and a SECRET in Oracle ATTACH")`.
  - Always create `auto state = make_shared_ptr<OracleCatalogState>(connection_string, wallet_path);`, call `state->ApplyOptions(info.options);`, and call `OracleCatalogState::Register(state, name);`.
  - Return `CreateOracleCatalog(db, state);`.
- In `OracleCreateTransactionManager` (`src/storage/oracle_storage_extension.cpp:101-114`):
  - Retrieve `auto state = OracleCatalogState::LookupByAlias(db.GetName());`.
  - Return `make_uniq<OracleTransactionManager>(db, state);`.

### Step 2: Synchronize `OracleTransactionManager::active` in `src/include/oracle_transaction_manager.hpp` and `src/storage/oracle_transaction_manager.cpp`

- Add `std::mutex transaction_lock;` to `OracleTransactionManager` (`src/include/oracle_transaction_manager.hpp:22`).
- Lock `std::lock_guard<std::mutex> guard(transaction_lock);` inside `StartTransaction` (`src/storage/oracle_transaction_manager.cpp:18-24`) and `EraseTransaction` (`src/storage/oracle_transaction_manager.cpp:36-46`).
