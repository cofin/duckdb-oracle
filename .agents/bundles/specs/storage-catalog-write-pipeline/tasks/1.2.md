# Task 1.2: Release catalog metadata connections after query, synchronize state getters, and parameterize catalog metadata SQL

## Objective

Remediate findings `H-24` (catalog connection pin part), `M-18` (catalog part), `M-19` (catalog part), `M-20`, and `L-09` (catalog part) in `src/include/oracle_catalog_state.hpp` and `src/storage/oracle_catalog.cpp`:
1. Remove the persistent `unique_ptr<OracleConnection> connection;` member from `OracleCatalogState` so `ExecuteMetadataQuery` and `ExecuteMetadataQueryWithStringBinds` acquire a scoped `OracleConnection` from `OracleConnectionManager` and return it to the pool immediately when the metadata query completes (fixing the 10s self-deadlock when `oracle_connection_limit = 1`).
2. Acquire `std::lock_guard<std::mutex> guard(lock);` in `GetCurrentSchema()` and `GetVersionInfo()` and return by value.
3. In `ListSchemas()`: include `"main"` when `lazy_schema_loading = false` and `use_current_schema = true`.
4. In `ListObjects()`: use `SELECT DISTINCT object_name`, trim and uppercase tokens from `settings.metadata_object_types`, return `{}` if no valid tokens remain, and bind parameters via `ExecuteMetadataQueryWithStringBinds`.
5. In `ResolveSynonym()`: filter `AND db_link IS NULL`, verify the target object is a `TABLE`, `VIEW`, or `MATERIALIZED VIEW` in `ALL_OBJECTS`, and use bind parameters.
6. Update `GetObjectName(const string &schema, const string &object, const string &object_type, string &out_owner, string &out_name)` and `GetRealSchemaName` to use `ExecuteMetadataQueryWithStringBinds` with exact-or-upper matching (`(col = :1 OR col = UPPER(:2))`).
7. Remove unused `unordered_map<string, vector<string>> table_cache` from `OracleCatalogState`.

## Context

- **Relevant Source Locations**:
  - `src/include/oracle_catalog_state.hpp:45-102`
  - `src/storage/oracle_catalog.cpp:60-460`

## Steps

### Step 1: Update `OracleCatalogState` in `src/include/oracle_catalog_state.hpp`

- Change `GetCurrentSchema()` and `GetVersionInfo()` to return `string` and `OracleVersionInfo` by value (protected by `lock`).
- Add `bool GetObjectName(const string &schema, const string &object, const string &object_type, string &out_owner, string &out_name);` while keeping the 2-argument `string GetObjectName(const string &schema, const string &object);` overload delegating to it so existing callers in `oracle_schema_entry.cpp` and `oracle_table_entry.cpp` continue to compile.
- Remove `unique_ptr<OracleConnection> connection;`, `OracleConnection &GetConnection();`, and `unordered_map<string, vector<string>> table_cache;`.

### Step 2: Release metadata connections and fix `ListSchemas`, `ListObjects`, `ResolveSynonym`, `GetRealSchemaName`, and `GetObjectName` in `src/storage/oracle_catalog.cpp`

- In `ExecuteMetadataQuery` and `ExecuteMetadataQueryWithStringBinds` (`src/storage/oracle_catalog.cpp:74-84`):
  - Instantiate a local `OracleConnection conn(connection_string, settings, wallet_path);` (after releasing `lock` or holding only what is needed for cache inspection) so the pooled handle is returned immediately upon scope exit.
- In `GetCurrentSchema()` and `GetVersionInfo()` (`src/storage/oracle_catalog.cpp:170-248`):
  - Hold `std::unique_lock<std::mutex> guard(lock);` when checking/populating `current_schema` and `version_info`.
- In `ListSchemas()` (`src/storage/oracle_catalog.cpp:250-284`):
  - When `settings.use_current_schema` is true and `"main"` is not already in `schemas`, prepend `"main"`.
- In `ListObjects()` (`src/storage/oracle_catalog.cpp:286-337`):
  - Parse `settings.metadata_object_types`, trim + `StringUtil::Upper` each non-empty token; if empty, cache and return `{}`.
  - Query `SELECT DISTINCT object_name FROM all_objects WHERE owner = :1 AND object_type IN (:2, ...) ORDER BY object_name` using `ExecuteMetadataQueryWithStringBinds`.
- In `ResolveSynonym()` (`src/storage/oracle_catalog.cpp:405-424`):
  - Query `SELECT table_owner, table_name FROM all_synonyms WHERE owner IN (:1, 'PUBLIC') AND (synonym_name = :2 OR synonym_name = UPPER(:3)) AND db_link IS NULL ORDER BY CASE WHEN owner = :4 THEN 0 ELSE 1 END, CASE WHEN synonym_name = :5 THEN 0 ELSE 1 END FETCH FIRST 1 ROWS ONLY` using `ExecuteMetadataQueryWithStringBinds`.
- In `GetRealSchemaName` and `GetObjectName`:
  - Use `ExecuteMetadataQueryWithStringBinds` with exact-first ordering (`ORDER BY CASE WHEN ... = :1 THEN 0 ELSE 1 END FETCH FIRST 1 ROWS ONLY`).
