# Task 1.3: Override DuckCatalog/DuckSchemaEntry virtuals and preserve target schema/table in PlanInsert

## Objective

Remediate findings `H-19` (schema entry part), `H-21`, and `L-08` (schema entry part) in `src/include/oracle_catalog.hpp` and `src/storage/oracle_schema_entry.cpp`:
1. Override `DuckCatalog` virtual methods on `OracleCatalog` (`InMemory`, `GetDBPath`, `IsEncrypted`, `GetEncryptionCipher`, `GetDatabaseSize`, `GetMetadataInfo`, `CreateSchema`, `DropSchema`, `PlanCreateTableAs`) so `SELECT * FROM duckdb_databases()`, `PRAGMA database_size`, `CREATE SCHEMA`, `DROP SCHEMA`, and `CREATE TABLE AS` never invoke `DuckCatalog::GetDatabase()` (`InternalException`) or `D_ASSERT(catalog_p.IsDuckCatalog())`.
2. Override `DuckSchemaEntry` DDL methods on `OracleSchemaEntry` (`CreateTable`, `CreateView`, `CreateSequence`, `CreateType`, `CreateIndex`, `CreateFunction`, `Alter`, `DropEntry`) to throw a clear `BinderException("Oracle catalog does not support direct DDL via attached schema; use oracle_execute(...) instead")` instead of crashing in `DuckSchemaEntry::AddEntry`.
3. Expose `shared_ptr<OracleCatalogState> GetState() const` on `OracleCatalog`.
4. In `OracleCatalog::PlanInsert`, extract the resolved Oracle `schema_name` and `table_name` from `op.table.Cast<OracleTableEntry>()` and pass both explicitly into `PhysicalOracleInsert`.
5. Remove the duplicate `catalog->Initialize(false);` call in `CreateOracleCatalog`.

## Context

- **Relevant Source Locations**:
  - `src/include/oracle_catalog.hpp:1-20`
  - `src/storage/oracle_schema_entry.cpp:25-215`

## Steps

### Step 1: Expose `OracleCatalog` interface in `src/include/oracle_catalog.hpp`

Declare `class OracleCatalog : public DuckCatalog` (or expose `GetOracleCatalogState(Catalog &catalog)`) in `src/include/oracle_catalog.hpp` so `OracleCreateTransactionManager` (`Task 1.1`) can access `state`.

### Step 2: Override `DuckSchemaEntry` and `DuckCatalog` virtual methods in `src/storage/oracle_schema_entry.cpp`

- On `OracleSchemaEntry`:
  - Override `CreateTable`, `CreateView`, `CreateSequence`, `CreateType`, `CreateIndex`, `CreateFunction`, `Alter`, and `DropEntry` to throw `BinderException("Oracle catalog does not support DDL operations directly; use oracle_execute() instead")`.
- On `OracleCatalog`:
  - Override:
    ```cpp
    bool InMemory() override { return false; }
    string GetDBPath() override { return RedactOracleConnectionString(state->connection_string); }
    bool IsEncrypted() const override { return false; }
    string GetEncryptionCipher() const override { return string(); }
    DatabaseSize GetDatabaseSize(ClientContext &context) override { return DatabaseSize(); }
    vector<MetadataBlockInfo> GetMetadataInfo(ClientContext &context) override { return {}; }
    optional_ptr<CatalogEntry> CreateSchema(CatalogTransaction transaction, CreateSchemaInfo &info) override {
        throw BinderException("Oracle catalog does not support CREATE SCHEMA; use oracle_execute() instead");
    }
    void DropSchema(ClientContext &context, DropInfo &info) override {
        throw BinderException("Oracle catalog does not support DROP SCHEMA; use oracle_execute() instead");
    }
    PhysicalOperator &PlanCreateTableAs(ClientContext &context, PhysicalPlanGenerator &planner, LogicalCreateTable &op,
                                        PhysicalOperator &plan) override {
        throw BinderException("Oracle catalog does not support CREATE TABLE AS; create the target table in Oracle first and use INSERT INTO");
    }
    ```
- In `OracleCatalog::PlanInsert` (`src/storage/oracle_schema_entry.cpp:165-193`):
  - Cast `auto &oracle_table = op.table.Cast<OracleTableEntry>();` and pass `oracle_table.GetSchemaName()` and `oracle_table.GetTableName()` to `planner.Make<PhysicalOracleInsert>(...)`.
- In `CreateOracleCatalog` (`src/storage/oracle_schema_entry.cpp:209-213`):
  - Remove `catalog->Initialize(false);` because `OracleAttach` / DuckDB initializes the catalog.
