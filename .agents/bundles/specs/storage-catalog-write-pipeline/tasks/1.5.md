# Task 1.5: Pass explicit schema/table to PhysicalOracleInsert, guard >64KB ub2 write lengths, bind DATE via SQLT_ODT, and optimize batch writes

## Objective

Remediate findings `H-19` (insert/write part), `H-23` (write part), `M-21`, `M-22` (write part), and `L-09` (write part) in `src/include/oracle_write.hpp`, `src/storage/oracle_write.cpp`, `src/include/oracle_insert.hpp`, and `src/storage/oracle_insert.cpp`:
1. Store explicit `string schema_name;` and `string table_name;` on `PhysicalOracleInsert` (adding an 8-argument constructor while keeping a delegating 7-argument overload so existing callers compile cleanly before Task `1.3`) instead of splitting `table_name` on `"."`.
2. In `OracleWriteGlobalState::Sink` / `BindColumn`, validate `str_val.size() <= NumericLimits<ub2>::Maximum()` (`65535`) before casting to `ub2`, throwing `InvalidInputException("Oracle write value for column '%s' exceeds maximum OCI bind length of 65535 bytes (%llu bytes)", col.column_name, static_cast<unsigned long long>(str_val.size()))`.
3. Support `SQLT_ODT` (`OCIDate`) binding in `OracleWriteColumnBuffer` and `BindColumn` for Oracle `DATE` targets when inserting `LogicalType::DATE`, `LogicalType::TIMESTAMP`, or `LogicalType::TIMESTAMP_TZ` (eliminating `ORA-01830` when `Timestamp::ToString` includes fractional microseconds).
4. Enrich `VECTOR` column dimension and element format from `ALL_VEC_COLUMNS` in `ResolveOracleWriteTargetMetadata`, and reuse shared helpers from `oracle_type_conversion.hpp`.
5. Convert string values once per batch in `Sink` (caching converted strings in a scratch vector) instead of calling `OracleWriteValueToString` twice in `Sink` and `BindColumn`, read primitive `SQLT_INT` and `SQLT_BDOUBLE` vectors via `FlatVector::GetData<T>`, make `OracleInsertGlobalState::insert_count` `std::atomic<idx_t>`, and remove unused `OracleWriteLocalState`.

## Steps

### Step 1: Update `PhysicalOracleInsert` and `OracleInsertGlobalState` in `src/include/oracle_insert.hpp` and `src/storage/oracle_insert.cpp`

- Add `string schema_name;` to `PhysicalOracleInsert` with an 8-argument constructor `(..., string schema_name, string table_name)` (plus a delegating 7-argument overload passing `""` for `schema_name`) and pass `schema_name, table_name` directly to `OracleWriteInitGlobal`.
- Change `OracleInsertGlobalState::insert_count` to `std::atomic<idx_t> insert_count {0};`.

### Step 2: Remove `OracleWriteLocalState`, add `SQLT_ODT` buffer support, and guard `ub2` lengths in `src/include/oracle_write.hpp` and `src/storage/oracle_write.cpp`

- Remove `OracleWriteLocalState` and `OracleWriteInitLocal`.
- Add `vector<OCIDate> date_values;` to `OracleWriteColumnBuffer`.
- In `OracleWriteGlobalState::Sink` / `BindColumn` (`src/storage/oracle_write.cpp:473-645`):
  - For `SQLT_ODT`: convert `DATE` or `TIMESTAMP` values into `OCIDate` (`OCIDateSetDate` + `OCIDateSetTime`, truncating fractional microseconds to whole seconds as required by Oracle `DATE`) and bind with `value_sz = sizeof(OCIDate)`, `dty = SQLT_ODT`.
  - For string-bound types (`SQLT_CHR`): convert each non-null row via `OracleWriteValueToString` once per batch, check `if (str_val.size() > NumericLimits<ub2>::Maximum()) throw InvalidInputException(...)`, and copy into `col_buf.char_buffer`.
  - In `ResolveOracleWriteTargetMetadata`, enrich `VECTOR` metadata from `ALL_VEC_COLUMNS` and use shared parsing helpers from `oracle_type_conversion.hpp`.
