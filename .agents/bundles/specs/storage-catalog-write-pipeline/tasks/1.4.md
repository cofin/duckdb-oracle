# Task 1.4: Restore original_types in OracleTableEntry::GetScanFunction, remove eager partition queries, and enrich VECTOR column metadata

## Objective

Remediate findings `H-22`, `M-18` (table entry part), `M-19` (table entry part), and `M-22` (table entry part) in `src/include/oracle_table_entry.hpp` and `src/storage/oracle_table_entry.cpp`:
1. Remove the unused `partition_metadata` member and eager `state->LoadPartitionMetadata(...)` call from `OracleTableEntry::Create` (saving 5 Oracle catalog round-trips per table lookup).
2. Add `const string &GetSchemaName() const` and `const string &GetTableName() const` accessors to `OracleTableEntry`.
3. In `OracleTableEntry::GetScanFunction`:
   - Restore `oracle_bind.original_types[i] = column_metadata[i].decision.duckdb_type;` alongside `return_types[i]`.
   - Widen `oracle_bind.oci_sizes[i] = 65535` whenever `column_metadata[i].decision.special_kind != OracleSpecialKind::NONE`.
4. In `OracleTableEntry::Create`: return `nullptr` if `cols.empty()` (instead of registering a broken 0-column `TableCatalogEntry`).
5. In `LoadColumns` and `LoadSpatialSRIDs`: use `ExecuteMetadataQueryWithStringBinds` with exact-or-upper matching, enrich `VECTOR` column dimension and element format from `ALL_VEC_COLUMNS` (falling back gracefully if `ALL_VEC_COLUMNS` does not exist on pre-23ai), and reuse shared integer parsing helpers from `oracle_type_conversion.hpp`.

## Context

- **Relevant Source Locations**:
  - `src/include/oracle_table_entry.hpp:15-40`
  - `src/storage/oracle_table_entry.cpp:15-242`

## Steps

### Step 1: Update `OracleTableEntry` in `src/include/oracle_table_entry.hpp`

- Remove `OraclePartitionMetadata partition_metadata;`.
- Add:
  ```cpp
  const string &GetSchemaName() const { return schema_name; }
  const string &GetTableName() const { return table_name; }
  ```

### Step 2: Parameterize `LoadSpatialSRIDs` and `LoadColumns` and enrich `VECTOR` metadata in `src/storage/oracle_table_entry.cpp`

- Use `state->ExecuteMetadataQueryWithStringBinds` in `LoadSpatialSRIDs` and `LoadColumns`.
- When any column has `data_type == "VECTOR"`, query `SELECT column_name, vector_dimension_count, vector_data_format FROM all_vec_columns WHERE owner = :1 AND table_name = :2` inside a `try { ... } catch (...) {}` block to populate `meta.vector_dimensions` and `meta.vector_format` (`FLOAT32`, `FLOAT64`, `INT8`, `BINARY`).
- In `OracleTableEntry::Create` (`src/storage/oracle_table_entry.cpp:147-171`):
  - Resolve `(real_schema, real_table)` via `state->GetObjectName` or `state->ResolveSynonym`.
  - If `cols.empty()`, return `nullptr`.
  - Remove `state->LoadPartitionMetadata(...)`.

### Step 3: Restore `original_types` and `oci_sizes` in `OracleTableEntry::GetScanFunction`

In `OracleTableEntry::GetScanFunction` (`src/storage/oracle_table_entry.cpp:223-235`):
```cpp
for (idx_t i = 0; i < column_metadata.size() && i < return_types.size(); i++) {
	return_types[i] = column_metadata[i].decision.duckdb_type;
	if (i < oracle_bind.original_types.size()) {
		oracle_bind.original_types[i] = column_metadata[i].decision.duckdb_type;
	}
	if (i < oracle_bind.oracle_type_names.size()) {
		oracle_bind.oracle_type_names[i] = column_metadata[i].decision.normalized_type;
		oracle_bind.pushdown_eligible[i] = column_metadata[i].decision.pushdown_eligible;
	}
	if (i < oracle_bind.oci_sizes.size() && column_metadata[i].decision.special_kind != OracleSpecialKind::NONE) {
		oracle_bind.oci_sizes[i] = 65535;
	}
}
```
