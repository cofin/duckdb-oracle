# Task 1.1: Fix VECTOR_SERIALIZE CLOB return, CHAR pushdown eligibility, TIMESTAMP_TZ, NUMBER(*,0), BINARY_FLOAT, and DATE write bind type

## Objective

Remediate findings `H-07` (registry part), `H-13` (registry part), `H-15` (registry part), `H-16` (registry part), `H-23` (registry part), `M-13`, `M-16`, and `L-06` (registry part) in `src/include/oracle_type_registry.hpp` and `src/oracle_type_registry.cpp`:
1. Change `VECTOR_SERIALIZE(%s)` to `VECTOR_SERIALIZE(%s RETURNING CLOB)` in `OracleTypeDecision::ConversionExpression`.
2. Distinguish `SQLT_AFC` (`normalized_type = "CHAR"`, `pushdown_eligible = false`) from `SQLT_CHR`/`SQLT_VCS`/`SQLT_AVC` (`normalized_type = "VARCHAR2"`, `pushdown_eligible = true`) in `ResolveOciDescribe`, and set `pushdown_eligible = false` for fixed-length `CHAR`/`NCHAR` in `ResolveMetadata`.
3. Parenthesize `&&`/`||` in `IsTimestampTZType` and `IsTimestampLTZType`.
4. Align unconstrained `NUMBER(*, 0)` (`precision == 0 && has_scale && scale == 0`) between `ResolveMetadata` and `ResolveOciDescribe`.
5. Map `BINARY_FLOAT` (`SQLT_BFLOAT`/`SQLT_IBFLOAT`) to `LogicalType::FLOAT` instead of `LogicalType::DOUBLE`.
6. Return `write_bind_type = SQLT_ODT` in `OracleTypeRegistry::ResolveWrite` when `decision.normalized_type == "DATE"` and `duckdb_type` is `DATE` or `TIMESTAMP`, and `SQLT_INT` when targeting integer `NUMBER(p, 0)` (`1 <= p <= 18`).
7. Remove unused `OracleTypeDecision::fetch_type` and dead `RAWTOHEX`/`TO_CHAR` LOB branches in `RequiresQueryRewrite` and `ConversionExpression`.

## Steps

### Step 1: Remove unused `fetch_type` from `OracleTypeDecision` in `src/include/oracle_type_registry.hpp`

In `src/include/oracle_type_registry.hpp:63`, remove `ub2 fetch_type = SQLT_STR;`.

### Step 2: Update `ConversionExpression`, `RequiresQueryRewrite`, and helper predicates in `src/oracle_type_registry.cpp`

- In `IsTimestampTZType` and `IsTimestampLTZType` (`src/oracle_type_registry.cpp:92-104`), parenthesize `(type.find("TIMESTAMP") != string::npos && type.find("WITH TIME ZONE") != string::npos)`.
- In `RequiresQueryRewrite` (`src/oracle_type_registry.cpp:116-126`) and `ConversionExpression` (`src/oracle_type_registry.cpp:128-160`):
  - Remove the unreachable `OracleSpecialKind::LOB_BLOB` and `OracleSpecialKind::LOB_CLOB` rewrite cases.
  - Change `OracleSpecialKind::VECTOR` to:
    ```cpp
    case OracleSpecialKind::VECTOR:
        return StringUtil::Format("VECTOR_SERIALIZE(%s RETURNING CLOB)", quoted_column_name);
    ```

### Step 3: Update `ResolveMetadata`, `ResolveOciDescribe`, and `ResolveWrite` in `src/oracle_type_registry.cpp`

- In `ResolveMetadata` (`src/oracle_type_registry.cpp:225-256`):
  - Map `type == "BINARY_FLOAT"` to `LogicalType::FLOAT`.
  - For `IsCharacterType(type)`: set `decision.pushdown_eligible = (type != "CHAR" && type != "NCHAR");`.
- In `ResolveOciDescribe` (`src/oracle_type_registry.cpp:258-314`):
  - Separate `case SQLT_AFC:` (`decision.normalized_type = "CHAR"; decision.pushdown_eligible = false;`) from `case SQLT_CHR: case SQLT_VCS: case SQLT_AVC:` (`decision.normalized_type = "VARCHAR2"; decision.pushdown_eligible = true;`).
  - For `SQLT_NUM`/`SQLT_VNU`: when `desc.precision == 0 && desc.has_scale && desc.scale == 0`, map to `LogicalType::DOUBLE` (matching `ResolveMetadata` so values `> INT64_MAX` do not throw `std::out_of_range` in `std::stoll`).
  - Map `case SQLT_BFLOAT: case SQLT_IBFLOAT:` to `LogicalType::FLOAT`.
- In `ResolveWrite` (`src/oracle_type_registry.cpp:328-336`):
  - When `decision.normalized_type == "DATE"` and `(duckdb_type.id() == LogicalTypeId::DATE || duckdb_type.id() == LogicalTypeId::TIMESTAMP || duckdb_type.id() == LogicalTypeId::TIMESTAMP_TZ)`, set `decision.write_bind_type = SQLT_ODT`.
  - When `decision.duckdb_type.id() == LogicalTypeId::BIGINT` and `duckdb_type.IsIntegral()`, set `decision.write_bind_type = SQLT_INT`.
