# Task 1.5: Fix scalar function multi-row iteration, VOLATILE stability, SELECT rejection, 64-bit row count, and DDL cache invalidation

## Objective

Remediate findings `H-17`, `M-17`, and `L-07` in `src/include/oracle_functions.hpp` and `src/oracle_functions.cpp`:
1. Loop over `for (idx_t row_idx = 0; row_idx < args.size(); row_idx++)` in `OracleExecuteFunction`, using `UnifiedVectorFormat` to read the connection and SQL arguments per row and write `result` per row.
2. In 0-arg scalar functions (`OracleClearCache`, `OracleDebugResetStatsFunction`, `OracleDebugLastQueryFunction`), set `result.SetVectorType(VectorType::CONSTANT_VECTOR)`.
3. Mark all side-effecting and stateful scalar functions (`oracle_execute`, `oracle_clear_cache`, `oracle_debug_reset_stats`, `oracle_debug_stats`, `oracle_debug_last_query`) with `FunctionStability::VOLATILE`.
4. In `OracleExecuteFunction`:
   - Call `RejectOracleWriteInExplicitTransaction(state.GetContext())`.
   - Inspect `OCI_ATTR_STMT_TYPE` *before* `OCIStmtExecute` and throw `InvalidInputException("oracle_execute does not support SELECT statements; use oracle_query instead")` when `stmt_type == OCI_STMT_SELECT`.
   - Read 64-bit `ub8 rows_affected = 0;` via `OCI_ATTR_UB8_ROW_COUNT` (clamped to `NumericLimits<int64_t>::Maximum()`).
   - Call `resolved.catalog_state->ClearCaches()` when DDL (`OCI_STMT_CREATE`, `OCI_STMT_DROP`, `OCI_STMT_ALTER`, `OCI_STMT_TRUNCATE`) succeeds on an attached catalog.
   - Remove the unreachable `else` branch checking `if (stmthp)` after `stmthp.get()` has already been dereferenced.

## Steps

### Step 1: Update `OracleExecuteFunction` in `src/oracle_functions.cpp`

In `src/oracle_functions.cpp:19-101`:
- Call `RejectOracleWriteInExplicitTransaction(state.GetContext());`.
- Convert `args.data[0]` and `args.data[1]` via `ToUnifiedFormat(args.size(), ...)`.
- Set `result.SetVectorType(VectorType::FLAT_VECTOR)`.
- For each `row_idx` in `0..args.size()`:
  - Validate neither argument is NULL or empty.
  - Resolve connection via `ResolveOracleConnection(state.GetContext(), conn_spec)`.
  - Prepare statement with `OCIStmtPrepare`, check `OCI_ATTR_STMT_TYPE` (`ub2 stmt_type = 0`), and reject `OCI_STMT_SELECT` with `InvalidInputException`.
  - Execute with `OCIStmtExecute(..., iters = 1, ..., OCI_COMMIT_ON_SUCCESS)`.
  - Read `ub8 rows_affected = 0;` via `OCI_ATTR_UB8_ROW_COUNT`.
  - If `resolved.catalog_state` is non-null and `stmt_type == OCI_STMT_CREATE || stmt_type == OCI_STMT_DROP || stmt_type == OCI_STMT_ALTER`, call `resolved.catalog_state->ClearCaches()`.
  - Write `rows_affected` into `FlatVector::GetData<int64_t>(result)[row_idx]`.

### Step 2: Set `CONSTANT_VECTOR` and `FunctionStability::VOLATILE` on all stateful scalar functions

In `src/oracle_functions.cpp:103-203`:
- In `OracleClearCache`, `OracleDebugResetStatsFunction`, and `OracleDebugLastQueryFunction`, set `result.SetVectorType(VectorType::CONSTANT_VECTOR)`.
- In `RegisterOracleFunctions`, set `.stability = FunctionStability::VOLATILE` on `oracle_execute`, `oracle_clear_cache`, `oracle_debug_reset_stats`, `oracle_debug_stats`, and `oracle_debug_last_query`.
