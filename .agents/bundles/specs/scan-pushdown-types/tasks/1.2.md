# Task 1.2: Fix BLOB AddStringOrBlob, TIMESTAMP_TZ offset parsing, locale-safe number/vector parsing, and shared conversion helpers

## Objective

Remediate findings `H-14`, `H-15` (conversion part), `M-15`, and `L-06` (conversion part) in `src/include/oracle_type_conversion.hpp` and `src/oracle_type_conversion.cpp`:
1. In `SetStringLikeValue`, call `StringVector::AddStringOrBlob(vector, string_t(ptr, len))` when `vector.GetType().id() == LogicalTypeId::BLOB` so binary `RAW`/`BLOB` payloads never trigger `StringVector::AddString`'s `D_ASSERT(type.id() == LogicalTypeId::VARCHAR)` or UTF-8 validation in debug builds.
2. In `ParseTimestamp`, pass `use_offset = true` to `Timestamp::TryConvertTimestamp` so `TIMESTAMP WITH TIME ZONE` strings containing `TZH:TZM` offsets are parsed and converted to UTC instead of silently dropping the timezone offset.
3. In `ParseDouble` / `ParseFloat` and `ParseVectorElement`, use locale-independent parsing (`duckdb::TryCast::Operation<string_t, double>`), and when `element_type.id() == LogicalTypeId::FLOAT`, verify `std::isfinite(static_cast<float>(val))` after narrowing to `float`.
4. In `ReadOracleString`, preserve exact `return_len` bytes when `return_len > 0` (only stripping a single trailing NUL terminator if present at `ptr[return_len - 1] == '\0'`), rather than truncating at the first embedded `\0`.
5. Export shared helpers (`TryParseMetadataInt`, `TryParseMetadataIndex`, `ParseOracleVectorLiteral`) in `oracle_type_conversion.hpp` so `oracle_write.cpp` and `oracle_table_entry.cpp` can reuse them in Chapter 3.

### Step 2: Fix `SetStringLikeValue`, `ReadOracleString`, `ParseTimestamp`, `ParseDouble`, and `ParseVectorElement` in `src/oracle_type_conversion.cpp`

- In `ReadOracleString` (`src/oracle_type_conversion.cpp:13-16`):
  ```cpp
  static string ReadOracleString(const char *ptr, ub2 return_len) {
      if (!ptr || return_len == 0) {
          return string();
      }
      size_t actual_len = (ptr[return_len - 1] == '\0') ? static_cast<size_t>(return_len - 1) : static_cast<size_t>(return_len);
      return string(ptr, actual_len);
  }
  ```
- In `SetStringLikeValue` (`src/oracle_type_conversion.cpp:19-22`):
  ```cpp
  static void SetStringLikeValue(Vector &vector, idx_t row_idx, const char *ptr, ub2 return_len) {
      auto value = ReadOracleString(ptr, return_len);
      auto data = FlatVector::GetData<string_t>(vector);
      if (vector.GetType().id() == LogicalTypeId::BLOB) {
          data[row_idx] = StringVector::AddStringOrBlob(vector, string_t(value.data(), value.size()));
      } else {
          data[row_idx] = StringVector::AddString(vector, value);
      }
  }
  ```
- In `ParseTimestamp` (`src/oracle_type_conversion.cpp:39-47`):
  - Pass `true` (`use_offset = true`) to `Timestamp::TryConvertTimestamp(str_val.c_str(), str_val.size(), result, true)`.
  - Also handle `LogicalTypeId::TIMESTAMP_TZ` in `ConvertOracleValueToDuckDB`.
- In `ParseDouble` and `ParseVectorElement` (`src/oracle_type_conversion.cpp:49-59,97-145`):
  - Parse via `TryCast::Operation<string_t, double>(string_t(trimmed.data(), trimmed.size()), val)`.
  - When `element_type.id() == LogicalTypeId::FLOAT`, cast `float fval = static_cast<float>(val);` and check `if (!std::isfinite(fval))` before returning `Value::FLOAT(fval)`.
