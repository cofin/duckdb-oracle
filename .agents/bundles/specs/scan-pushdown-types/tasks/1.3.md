# Task 1.3: Fix complex filter pushdown column/type preservation, empty-string/NaN/Inf/Date literal safety, and LIKE pushdown

## Objective

Remediate findings `H-09` (pushdown part), `H-10` (pushdown part), `H-11`, `H-12`, `H-13` (pushdown part), `M-11` (pushdown part), `M-12`, `M-14`, and `L-05` in `src/include/oracle_pushdown.hpp` and `src/oracle_pushdown.cpp`:
1. In `OraclePushdownComplexFilter`, stop destructively shrinking `bind.column_names`, `bind.oci_types`, `bind.oci_sizes`, `bind.oracle_type_names`, or `bind.pushdown_eligible`, and stop overwriting `get.returned_types` with re-described `VARCHAR` types; store pushed filter clauses in `bind.pushdown_clauses` and let `OracleInitGlobal` construct the final projected query after `RemoveUnusedColumns`.
2. In `ConstantToSQL`:
   - Return `false` when a `VARCHAR` constant is empty (`str_val.empty()`) so Oracle's `'' IS NULL` semantics never corrupt `=`, `<>`, `<`, `<=`, `>`, `>=`, `BETWEEN`, or `IN`.
   - Return `false` when a `FLOAT` or `DOUBLE` constant is `!std::isfinite(val)` so `nan`, `inf`, and `-inf` are never emitted as unquoted Oracle identifiers.
   - Return `false` when a `DATE` or `TIMESTAMP` constant is `!Date::IsFinite(date_val)` / `!Timestamp::IsFinite(ts_val)` or has `year < 1 || year > 9999`.
   - When pushing a `TIMESTAMP` constant with zero fractional microseconds (`time_part % Interval::MICROS_PER_SEC == 0`) against an Oracle `"DATE"` column, emit `TO_DATE('YYYY-MM-DD HH24:MI:SS', 'YYYY-MM-DD HH24:MI:SS')` to preserve Oracle B-tree index scans.
3. In `CanPushdownLike`, accept `"OCI CHARACTER"`; in `TryExtractLike` / `TryExtractPrefix` / `TryExtractSuffix` / `TryExtractContains`, return `false` when the pattern string is empty `""`.
4. In `OraclePushdownPlan::BuildQuery`, wrap `base_query` with newlines (`" FROM (\n" + base_query + "\n)"`) so trailing `--` comments cannot comment out the closing `)` and `WHERE` clause.

## Steps

### Step 1: Harden `ConstantToSQL` in `src/oracle_pushdown.cpp`

In `ConstantToSQL` (`src/oracle_pushdown.cpp:32-76`), add an optional `const string &oracle_type_name = ""` parameter:
- `LogicalTypeId::VARCHAR`:
  ```cpp
  auto str_val = StringValue::Get(val);
  if (str_val.empty()) {
      return false;
  }
  out = "'" + EscapeSQLString(str_val) + "'";
  return true;
  ```
- `LogicalTypeId::FLOAT` / `LogicalTypeId::DOUBLE`:
  ```cpp
  double dval = val.GetValue<double>();
  if (!std::isfinite(dval)) {
      return false;
  }
  out = val.ToString();
  return true;
  ```
- `LogicalTypeId::DATE`:
  ```cpp
  auto date_val = DateValue::Get(val);
  if (!Date::IsFinite(date_val)) {
      return false;
  }
  int32_t year = Date::ExtractYear(date_val);
  if (year < 1 || year > 9999) {
      return false;
  }
  out = "DATE '" + Date::ToString(date_val) + "'";
  return true;
  ```
- `LogicalTypeId::TIMESTAMP`:
  ```cpp
  auto ts_val = TimestampValue::Get(val);
  if (!Timestamp::IsFinite(ts_val)) {
      return false;
  }
  date_t date_part;
  dtime_t time_part;
  Timestamp::Convert(ts_val, date_part, time_part);
  int32_t year = Date::ExtractYear(date_part);
  if (year < 1 || year > 9999) {
      return false;
  }
  if (oracle_type_name == "DATE" && (time_part.micros % Interval::MICROS_PER_SEC == 0)) {
      int32_t hour, min, sec, micros;
      Time::Convert(time_part, hour, min, sec, micros);
      out = StringUtil::Format("TO_DATE('%s %02d:%02d:%02d', 'YYYY-MM-DD HH24:MI:SS')",
                               Date::ToString(date_part), hour, min, sec);
      return true;
  }
  out = "TIMESTAMP '" + Timestamp::ToString(ts_val) + "'";
  return true;
  ```
